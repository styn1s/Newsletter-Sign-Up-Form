# 📬 Newsletter Sign-Up Form
A clean, interactive sign-up form page designed for a product management newsletter. It features a main subscription form and a success state, with a focus on user experience and accessibility.

![Screenshot of the app](/images/screenshot.png)

## ✨ Features
- Email Validation: Checks for a properly formatted email address before submission.

- Interactive Feedback: Displays a success message upon valid subscription.

- Responsive Design: Adapts seamlessly to different screen sizes (mobile, tablet, desktop).

- Accessibility: Includes recent fixes to improve usability for all users.

- Modern UI: Minimalistic and visually appealing interface.

## 🚀 Live Demo
Try the live version here: https://styn1s.github.io/Newsletter-Sign-Up-Form/

## 🛠️ Technologies Used
- HTML5: For form structure and content.

- CSS3: For styling, layout, and responsive design.

- JavaScript: For form validation and interactivity.

## 🧪 How to Use
1. Enter a valid email address in the input field.

2. Click the "Subscribe to monthly newsletter" button.

3. If the email is valid, you will be redirected to the success page.

4. On the success page, click the "Dismiss message" button to return to the main form.
